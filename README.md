# Design and Implementation of a Heterogeneous Real-Time Keyword Spotting System on Cyclone-V SoC FPGA using HLS and Python-driven Linux Integration

This repository hosts the official implementation of the heterogeneous real-time Keyword Spotting (KWS) framework orchestrated with Intel HLS hardware acceleration and Python-driven Linux custom Kernel DMA integration.
